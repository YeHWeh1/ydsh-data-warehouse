ydsh_dwd.dwd_order — 订单事实表（一行一单）（15,000 行）
  order_id string  订单编号（主键）
  user_id string  用户编号（外键 → dim_user）
  store_id string  门店编号（外键 → dim_store）
  order_timestamp string  下单完整时间 yyyy-MM-dd HH:mm:ss（日期+时间合并）
  order_hour int  下单小时（时间字段拆分）
  pay_amount double  实付金额（负值已取绝对值，超大值已置空）
  discount_amount double  优惠金额
  net_amount double  净额 = 实付 - 优惠
  pay_type_code string  支付方式编码（关联 dim_pay_type）
  pay_type string  支付方式中文名
  order_status_code string  订单状态编码
  order_status string  订单状态中文名
  channel_code string  渠道编码
  channel string  下单渠道
  amount_flag int  0=正常 1=负金额已修正 2=超大金额已置空
  discount_flag int  1=负优惠金额已修正
  is_valid_amount int  1=金额可参与统计
  order_date string  下单日期分区键
