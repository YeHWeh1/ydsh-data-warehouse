## 三、回来后要做的（按顺序）

### ① 先修这处（最重要，5 分钟）

**问题**：`第1周/scripts/run-all.ps1` 里 ODS 导入那段，我刚加了改用 Python 执行器的编辑，
但**编辑因文件变更被拒绝，没生效**。当前该文件里还是旧的 `Get-Content | docker exec` 写法。

**为什么必须修**：`Get-Content -Raw -Encoding UTF8` 会把 BOM 写进管道，beeline 报
`ParseException line 1:0 character '﻿' not supported here`，建表全失败。
虽然我已经把「失败要如实报红」加进去了（不会再误报成功），但从零重建仍会失败。

**修法**：把 `第1周/scripts/run-all.ps1` 第 84~110 行左右的 ODS 段，改成调用：

```powershell
$runner = Join-Path (Split-Path -Parent $Root) '第4周\scripts\hive_run_sql.py'
& $py $runner $p
```

`第4周/scripts/hive_run_sql.py` **已经写好并测试通过**（能正确去 BOM）。

> ⚠️ 改完记得确认文件有 **UTF-8 BOM**（`head -c 3 | od -An -tx1` 应为 `ef bb bf`），
> 否则 PowerShell 5.1 按 GBK 读会乱码。
